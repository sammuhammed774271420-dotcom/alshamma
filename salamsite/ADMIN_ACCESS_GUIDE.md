# دليل الوصول إلى لوحة التحكم

## كيفية الدخول إلى لوحة التحكم الإدارية

### 1. الرابط الأساسي
```
http://salamsite1.kesug.com/admin/login.php
```

### 2. بيانات الدخول الافتراضية
- **البريد الإلكتروني**: `admin@salamsite1.kesug.com`
- **كلمة المرور**: `admin123`

### 3. بعد تسجيل الدخول
سيتم تحويلك تلقائياً إلى لوحة التحكم الرئيسية:
```
http://salamsite1.kesug.com/admin/dashboard.php
```

## الأقسام الرئيسية في لوحة التحكم:

### 📊 لوحة التحكم (Dashboard)
- عرض إحصائيات الموقع
- عدد المشاريع، الخدمات، فريق العمل
- رسائل التواصل الجديدة

### 🏗️ إدارة المشاريع (Projects)
- إضافة مشاريع جديدة
- تعديل المشاريع الموجودة
- حذف المشاريع
- رفع صور للمشاريع
- تحديد حالة المشروع (قيد التنفيذ / مكتمل)

### 🛠️ إدارة الخدمات (Services)
- إضافة خدمات جديدة
- تعديل الخدمات
- حذف الخدمات
- ترتيب الخدمات
- رفع أيقونات الخدمات

### 👥 إدارة الفريق (Team)
- إضافة أعضاء جدد
- تعديل بيانات الأعضاء
- حذف الأعضاء
- رفع صور شخصية
- إضافة معلومات الاتصال

### 📝 إدارة المحتوى (About)
- تحرير محتوى "من نحن"
- إضافة الإحصائيات
- رفع صور للمحتوى
- معاينة التغييرات

### ✉️ إدارة الرسائل (Contact)
- عرض رسائل الزوار
- تحديث حالة الرسائل
- الرد على الرسائل
- حذف الرسائل غير المهمة

### ⚙️ الإعدادات (Settings)
- تغيير كلمة المرور
- تحديث معلومات الموقع
- إعدادات العرض

## نصائح أمنية مهمة:

### 1. تغيير كلمة المرور فوراً
- انتقل إلى قسم الإعدادات
- اختر "تغيير كلمة المرور"
- استخدم كلمة مرور قوية

### 2. حماية مجلد admin
- يمكن تغيير اسم المجلد من `admin` إلى أي اسم آخر
- تحديث جميع الروابط الداخلية

### 3. استخدام HTTPS
- تأكد من تفعيل شهادة SSL
- جميع الروابط يجب أن تكون عبر HTTPS

## استكشاف الأخطاء:

### المشكلة: لا يمكن الدخول
**الحل**:
- تأكد من رفع جميع ملفات المشروع
- تحقق من صحة بيانات قاعدة البيانات في `config.php`
- تأكد من تفعيل الجلسات (sessions) في PHP

### المشكلة: خطأ في قاعدة البيانات
**الحل**:
- راجع بيانات الاتصال في `config.php`
- تأكد من إنشاء قاعدة البيانات
- تحقق من صلاحيات المستخدم

### المشكلة: الصفحة تظهر فارغة
**الحل**:
- تفعيل عرض الأخطاء في PHP:
```php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```
- مراجعة سجلات الأخطاء في الاستضافة

## روابط سريعة:
- الصفحة الرئيسية: `/index.php`
- نموذج الاتصال: `/contact-form.php`
- تسجيل الخروج: `/admin/logout.php`
