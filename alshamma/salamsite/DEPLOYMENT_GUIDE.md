# دليل نشر موقع شركة السلام للعقارات

## المتطلبات الأساسية

### 1. بيئة الاستضافة
- استضافة تدعم PHP 7.4 أو أعلى
- قاعدة بيانات MySQL 5.7 أو أعلى
- دعم SSL (شهادة أمان)
- مساحة تخزين مناسبة (على الأقل 500MB)
- نطاق (Domain) أو نطاق فرعي (Subdomain)

### 2. المتطلبات التقنية
- PHP مع دعم PDO و MySQLi
- تفعيل خاصية file_uploads في PHP
- حد أقصى لرفع الملفات (upload_max_filesize) على الأقل 10MB
- دعم GD Library لمعالجة الصور

## خطوات النشر

### الخطوة 1: تحضير قاعدة البيانات

1. **تسجيل الدخول إلى لوحة تحكم الاستضافة** (cPanel, Plesk, إلخ)

2. **إنشاء قاعدة بيانات جديدة**:
   - الذهاب إلى "قواعد البيانات" (Databases)
   - إنشاء قاعدة بيانات جديدة (مثل: salamsite_db)
   - إنشاء مستخدم جديد لقاعدة البيانات
   - إضافة المستخدم إلى قاعدة البيانات مع منح جميع الصلاحيات

3. **تسجيل بيانات قاعدة البيانات**:
   - اسم قاعدة البيانات
   - اسم المستخدم
   - كلمة المرور
   - اسم الخادم (localhost عادة)

### الخطوة 2: رفع الملفات إلى الاستضافة

1. **الذهاب إلى مدير الملفات** (File Manager) في لوحة التحكم

2. **الذهاب إلى المجلد الرئيسي** (public_html أو www)

3. **رفع جميع ملفات المشروع**:
   - يمكن رفع الملفات كملف ZIP وفك الضغط
   - أو استخدام FTP (FileZilla, WinSCP, إلخ)

4. **تحديد الأذونات** (Permissions):
   ```
   uploads/          755
   uploads/projects/ 755
   uploads/team/     755
   uploads/about/    755
   ```

### الخطوة 3: إعداد التكوين

1. **تعديل ملف config.php**:

```php
<?php
// Application Configuration
define('APP_NAME', 'شركة السلام للعقارات');
define('APP_URL', 'http://salamsite1.kesug.com'); // تغيير إلى نطاقك
define('UPLOAD_DIR', 'uploads/');
define('MAX_FILE_SIZE', 10 * 1024 * 1024); // 10MB
define('ALLOWED_EXTENSIONS', ['jpg', 'jpeg', 'png', 'gif', 'webp']);
?>
```

2. **تعديل ملف database.php**:

```php
<?php
// Database configuration
$host = 'localhost'; // أو اسم الخادم من الاستضافة
$dbname = 'salamsite_db'; // اسم قاعدة البيانات التي أنشأتها
$username = 'your_username'; // اسم مستخدم قاعدة البيانات
$password = 'your_password'; // كلمة مرور قاعدة البيانات

try {
    $pdo = new PDO("mysql:host=$host;dbname=$dbname;charset=utf8", $username, $password);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    die("Database connection failed: " . $e->getMessage());
}

// Create tables if they don't exist
// ... (الكود الموجود)
?>
```

### الخطوة 4: تشغيل الموقع

1. **الذهاب إلى الموقع**: http://salamsite1.kesug.com

2. **تسجيل الدخول إلى لوحة التحكم**:
   - الرابط: http://salamsite1.kesug.com/admin/login.php
   - البريد الإلكتروني الافتراضي: admin@salamsite1.kesug.com
   - كلمة المرور الافتراضية: admin123

3. **تغيير كلمة مرور المشرف** فوراً:
   - الذهاب إلى الإعدادات في لوحة التحكم
   - تغيير كلمة المرور الافتراضية

### الخطوة 5: إعداد البريد الإلكتروني (اختياري)

1. **تعديل إعدادات البريد في contact-form.php**:

```php
$from = 'noreply@salamsite1.kesug.com'; // بريد من نطاقك
```

2. **إعداد SMTP** (موصى به):
   - استخدام مكتبة PHPMailer
   - إعدادات SMTP من الاستضافة:
     - SMTP Host: smtp.salamsite1.kesug.com
     - SMTP Port: 587 أو 465
     - SMTP Authentication: نعم
     - SMTP Username: بريدك الإلكتروني
     - SMTP Password: كلمة مرور البريد

### الخطوة 6: إعداد SSL (شهادة أمان)

1. **تفعيل SSL**:
   - في cPanel: SSL/TLS Status → Manage SSL Sites
   - أو استخدام Let's Encrypt المجاني

2. **إعادة توجيه HTTP إلى HTTPS**:
   - إضافة الكود التالي إلى ملف .htaccess:

```
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

### الخطوة 7: تحسين الأداء

1. **تفعيل التخزين المؤقت** (Caching):
   - تفعيل OPcache في PHP
   - تفعيل Gzip Compression

2. **تحسين الصور**:
   - ضغط الصور قبل الرفع
   - استخدام تنسيق WebP للصور الحديثة

3. **إعداد CDN** (اختياري):
   - Cloudflare مجاني
   - تحسين سرعة التحميل عالمياً

## إعدادات الأمان المهمة

### 1. حماية لوحة التحكم
- تغيير مسار مجلد admin (اختياري)
- تقييد الوصول عن طريق IP (اختياري)
- تفعيل المصادقة الثنائية (2FA)

### 2. حماية قاعدة البيانات
- استخدام كلمات مرور قوية
- عدم استخدام اسم المستخدم الافتراضي
- تحديث PHP و MySQL بانتظام

### 3. حماية الملفات
- تعيين أذونات مناسبة (755 للمجلدات، 644 للملفات)
- منع الوصول إلى ملفات config:
  ```
  <Files "config.php">
      Order Allow,Deny
      Deny from all
  </Files>
  ```

### 4. منع الهجمات
- تفعيل ModSecurity في الاستضافة
- تحديث الملفات بانتظام
- عمل نسخ احتياطية دورية

## النسخ الاحتياطي

### 1. نسخ احتياطي لقاعدة البيانات:
```sql
# عبر phpMyAdmin:
- اختر قاعدة البيانات
- انقر على "Export"
- اختر "Quick" و "SQL"
- انقر على "Go"

# أو عبر سطر الأوامر:
mysqldump -u username -p database_name > backup.sql
```

### 2. نسخ احتياطي للملفات:
- نسخ مجلد كامل المشروع عبر FTP
- أو استخدام أداة النسخ الاحتياطي في لوحة التحكم

## استكشاف الأخطاء الشائعة

### المشكلة: خطأ في الاتصال بقاعدة البيانات
**الحل**:
- التأكد من صحة بيانات الاتصال في database.php
- التأكد من أن قاعدة البيانات موجودة
- التأكد من أن المستخدم لديه صلاحيات

### المشكلة: لا يمكن رفع الصور
**الحل**:
- التأكد من وجود مجلد uploads
- تعيين أذونات 755 للمجلدات
- زيادة upload_max_filesize في php.ini

### المشكلة: البريد الإلكتروني لا يعمل
**الحل**:
- استخدام SMTP بدلاً من mail()
- التحقق من إعدادات SPF و DKIM
- استخدام مكتبة PHPMailر

### المشكلة: تنسيق الموقع غير صحيح
**الحل**:
- التأكد من رفع جميع الملفات
- التحقق من مسارات CSS و JavaScript
- تفعيل display_errors في PHP للتصحيح

## الصيانة الدورية

### أسبوعياً:
- التحقق من عمل النماذج (contact form)
- مراجعة الرسائل الجديدة في لوحة التحكم
- التحقق من مساحة التخزين

### شهرياً:
- تحديث المحتوى (المشاريع، الخدمات)
- مراجعة النسخ الاحتياطية
- فحص أداء الموقع (PageSpeed Insights)

### ربع سنوياً:
- تحديث PHP إلى أحدث إصدار آمن
- مراجعة أمان الموقع
- تحسين الصور والملفات

## نصائح إضافية

1. **استخدام Cloudflare**:
   - حماية من الهجمات
   - تسريع الموقع
   - مجاني وسهل الإعداد

2. **تفعيل Gzip Compression**:
   - تقليل حجم الملفات
   - تحسين سرعة التحميل

3. **تحسين الصور**:
   - استخدام أدوات مثل TinyPNG
   - تحديد أبعاد مناسبة للصور

4. **مراقبة الأداء**:
   - Google Analytics
   - Google Search Console
   - Uptime monitoring

5. **SEO الأساسي**:
   - إضافة meta tags في pages
   - إنشاء sitemap.xml
   - إعداد robots.txt

## الدعم الفني

في حالة وجود مشاكل:
1. تفعيل عرض الأخطاء:
```php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```

2. مراجعة سجلات الأخطاء:
   - error_log في مجلد الموقع
   - سجلات الاستضافة (cPanel → Metrics → Errors)

3. التواصل مع دعم الاستضافة

## ملاحظات مهمة

- احفظ نسخة احتياطية قبل أي تحديث
- اختبر الموقع على استضافة تجريبية أولاً
- احتفظ ببيانات قاعدة البيانات في مكان آمن
- قم بتحديث كلمات المرور بانتظام
- راقب استخدام الموارد (CPU, Memory)
